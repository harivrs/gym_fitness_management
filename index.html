Database & Backend Architecture

FitPulse runs on a 3-Tier Software Architecture: Frontend UI → Node.js Express REST API → SQLite3 Relational Database (fitpulse.db).

Software Engineering 3-Tier Architecture:
• Presentation Tier: HTML5, CSS3, ES6 JavaScript, Chart.js
• Application Tier: Node.js (v24), Express 5 REST API (/api/*)
• Database Tier: SQLite3 (fitpulse.db) with Relational Schema, ACID Transactions, and Foreign Keys

Relational Schema & Foreign Key Constraints
SQLite Relational Architecture design with Referential Integrity:
members (PK: id, FK: trainerId → trainers.id)
trainers (PK: id)
classes (PK: id, FK: trainerId → trainers.id)
class_enrollments (Junction M:N: classId → classes.id, memberId → members.id)
equipment (PK: id)
activities (PK: id, timestamp)
settings (PK: id = 1)
